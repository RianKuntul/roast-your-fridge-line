Entry for [One Line, One Laugh: Roast Your Fridge](https://make.fun/c/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521) on make.fun.

`main.ts` (Node 22, erasable TypeScript) writes a single roast line — one line, at most 200 characters — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `./output/entry.txt` when unset). The line is a fixed string: deterministic, no network, no randomness.

The roast:

> My fridge has a light that only works when the door is open, so the leftovers vanish in the dark — turns out it has been eating better than me.

Run it:

```sh
node main.ts
```
